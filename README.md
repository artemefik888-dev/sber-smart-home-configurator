# Конфигуратор «Умный дом Sber»

Публичный интерактивный калькулятор оборудования для типовых квартир: готовые комплектации по помещениям и категориям, ручная сборка, спецификация, сценарии и экспорт.

[![GitHub Pages](https://github.com/artemefik888-dev/sber-smart-home-configurator/actions/workflows/deploy-pages.yml/badge.svg)](https://github.com/artemefik888-dev/sber-smart-home-configurator/actions/workflows/deploy-pages.yml)

## Возможности

- 4 типа квартир × 2 готовых способа расчёта = 8 готовых вариантов;
- режимы «По помещениям», «По категориям» и «Собрать самостоятельно»;
- белый и карбоновый цвет оборудования;
- независимое сохранение выбора помещений и категорий в одном проекте;
- подарок «Умная прихожая» и рекомендуемый модуль защиты от протечек без дублей;
- подробная спецификация с поиском, фильтрами, SKU, количеством, РРЦ и суммой;
- полный каталог из 42 позиций с карточками и изображениями из прайс-листа;
- визуальная загрузка собственного плана в PDF, JPG или PNG без распознавания;
- предупреждения об отсутствии хаба и минимальном заказе 15 000 ₽ без автоматического изменения состава;
- клиентский вид, сравнение вариантов и сценарии;
- экспорт в Excel и PDF;
- импорт двух обновлённых Excel-файлов с валидацией до применения;
- адаптивный интерфейс для компьютеров и планшетов.

## Локальный запуск

Требуется Node.js 22.13 или новее и pnpm 11.19.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

После запуска откройте [http://localhost:5173](http://localhost:5173).

## Проверка и production-сборка

```bash
pnpm test
pnpm lint
pnpm build
pnpm start
```

Production-файлы создаются в `dist/`. Конфигурация Vite автоматически использует путь `/<имя-репозитория>/` в GitHub Actions, поэтому JavaScript, CSS, логотип и изображения товаров работают на GitHub Pages не из корня домена.

## Автоматическая публикация

Workflow `.github/workflows/deploy-pages.yml` запускается при каждом push в `main` и вручную через вкладку Actions. Он устанавливает Node.js и pnpm, выполняет тесты и lint, собирает статический сайт и публикует артефакт через официальные GitHub Pages Actions.

## Данные и расчёты

- `app/data/default-data.json` — нормализованный встроенный набор для публичного приложения;
- `public/products/` — изображения, однозначно сопоставленные с SKU;
- `app/data/types.ts` — контракт данных;
- `app/lib/calculations.ts` — расчётное ядро.

Оригинальные Excel-файлы расчётов и прайс-листа не входят в публичный репозиторий. Для обновления встроенного набора поместите их локально в `source-data/`, запустите `python3 scripts/build_default_data.py`, затем выполните тесты и новую публикацию. Подробный порядок описан в [инструкции по обновлению](docs/data-update.md).

Итог всегда пересчитывается по подробным строкам как `количество × актуальная РРЦ`, а не берётся из итоговых формул исходного Excel.

## Локальное хранение

Авторизации и серверной базы нет. Сохранённые проекты и данные, применённые через экран «Обновление данных», хранятся только в `localStorage` текущего браузера. Очистка данных сайта в браузере удалит эти проекты.

Не вводите в приложение персональные, конфиденциальные или иные чувствительные сведения: браузерное хранилище не предназначено для их защищённой обработки.
