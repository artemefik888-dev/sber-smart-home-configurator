# Аудит исходных материалов

## Правило приоритета

При противоречиях использовался согласованный порядок: документ «4 блока» → опросник из 220 вопросов → дополненный короткий ответ → первый короткий ответ → исходное ТЗ. Документ с пожеланиями ко второй версии использован только для фиксации границ V2. Названия и цены взяты из актуального прайс-листа, а состав, количества, помещения, категории и признаки подарка — из файла типовых планировок. Связь выполняется по SKU.

## Что найдено

- каталог: 42 товара, дублей SKU нет, некорректных цен нет;
- 8 цен представлены внешними формулами, но у всех есть сохранённые числовые значения;
- типовые наборы: 152 подробные строки, 15 уникальных SKU;
- все 15 SKU найдены в каталоге;
- сценарии: 5 для света, 3 для климата, 5 для безопасности;
- изображения отсутствуют или не сопоставляются однозначно только для `ATN000117Z` и `SBDV-00171V`; для них используется нейтральная заглушка.

## Обнаруженные расхождения

1. В белом блоке 1К для подарочного выключателя сохранена старая цена 5 990 ₽; каталог содержит 3 990 ₽.
2. В нескольких строках типового файла сохранены старые цены, отличающиеся от текущего прайс-листа.
3. Формула белого итога 2К не включает сумму ванной.
4. Внутренний заголовок листа 3К ошибочно называет квартиру двухкомнатной.

Приложение не использует старые цены и итоговые формулы типового файла. Оно берёт название и РРЦ из каталога, а сумму рассчитывает заново по каждой строке. Для 3К используется имя листа, а не ошибочный внутренний заголовок.
